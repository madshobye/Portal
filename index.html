Guide for Using Portal

Portal is a p5.js v2+ helper layer for rapid sketch prototyping with camera, speech, GPT, tracking, UI, mapping, QR, and machine learning modules. This page is a practical guide based on the README, with direct links to live examples and source code.

Quick Start

Best Default Workflow

  • Start from the cloud base sketch or the local `baseSketch` example.
  • Use `async setup()` and `await pSetup()`.
  • Load Portal modules with `await loadScript("portal/<module>.js")`.
  • Prefer a single copy-paste-friendly `sketch.js` unless multi-file output is requested.
  • Use simple `draw()` polling with `hasNewResult()` / `consumeNew()`.
  • Avoid `preload()` for Portal workflows in p5.js v2+.
  • Use Portal’s `SoundFile` helper instead of old p5 sound-loading patterns.
Instructions For LLMs

Write Beginner-Friendly Portal Code

Use p5.js v2+ patterns

Write `async setup()`, use `await`, and do not rely on `preload()` for Portal assets or modules.

Prefer simple state

Use a few top-level variables, a clear `draw()` loop, and polling instead of deeply nested callbacks.

Use Portal modules directly

Load `portal/speech.js`, `portal/GptClient.js`, `portal/mapper.js`, and other modules with `loadScript(...)` instead of reimplementing loaders.

Skip redundant resize/fullscreen code

Portal already covers common canvas resize behavior. Only add `windowResized()` or `f` fullscreen shortcuts if the sketch truly needs them.

Best Practices

What Usually Works Well

  • One clear idea per sketch.
  • Render first, then draw overlays or detections on top.
  • Use Portal UI helpers for simple controls before building custom DOM.
  • Use structured GPT output when a sketch depends on predictable fields.
  • Stop speech recognition before speech output if self-echo is a risk.
  • Use visible status text or `uiDebug(...)` for errors.
Common Pitfalls

What To Avoid

  • Using `preload()` for Portal module loading.
  • Mixing many unrelated technologies in one beginner sketch.
  • Adding event-driven complexity when a simple polling loop is enough.
  • Using old p5 sound-loading patterns instead of `portal/SoundFile.js`.
  • Adding sketch-local resize handlers that only duplicate Portal behavior.
