Capability

AI-assisted making

The AI view is a project workspace, not a separate chat toy. It helps draft scripts, maintain a specification, and keep revision-specific reasoning near the code that came from it.

How It Works

  1. The current revision provides context. The assistant sees the project specification, selected code, and API guidance.
  2. Chat can generate or revise code. A useful answer should produce a complete script when the goal is code.
  3. The specification records intent. Good specifications describe behavior, parts, assumptions, and constraints so the next revision has memory.
  4. Circuit comments help diagrams. `// xobit-circuit:` comments near pin variables tell the Circuit view about physical parts the code alone cannot prove.
  5. The API key stays local. AI settings are stored in the browser unless you explicitly create a sharing key.

Useful Prompts

Make this sketch non-blocking and keep the same behavior.
Add a slider for brightness and a button to reset the animation.
Update the specification to match this code and list wiring assumptions.
Explain why this compile error happens before changing the sketch.
