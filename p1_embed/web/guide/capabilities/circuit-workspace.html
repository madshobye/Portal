Circuit workspace

The Circuit view keeps wiring assumptions visible while the project evolves. It can infer common parts from script code and use `xobit-circuit` comments when a physical part cannot be inferred safely.

How It Works

  1. Code creates evidence. Pin variables, LED setup calls, servo calls, and comments give the Circuit view clues.
  2. Parts are inferred cautiously. The browser prefers explicit evidence over guessing, especially for power, relays, motors, and sensors.
  3. Assumptions stay visible. The page lists what it inferred and what it could not know, so wiring risk is not hidden.
  4. Revision context matters. Circuit notes belong to the current project revision with the code that produced them.

Comment Pattern

Use comments near pin variables when you know the physical role but the code only says “pin”.

var stripPin = 16; // xobit-circuit: IO16 ledStrip
var relayPin = 18; // xobit-circuit: IO18 relay
var knobPin = 34; // xobit-circuit: IO34 potentiometer
