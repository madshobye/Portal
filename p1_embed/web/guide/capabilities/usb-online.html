USB and online control

USB is the trusted desk connection. MQTT is the online path once the board joins WiFi. Both transports aim at the same project workflow: upload scripts, read logs, receive UI events, and inspect board state.

Connection Roles

usbUSB

Used for first install, recovery, direct development, and trusted local communication through Web Serial in Chrome-based browsers.

cloudOnline MQTT

Used when the board is on WiFi and should be controlled without a cable. MQTT carries commands, responses, events, logs, and script uploads.

How It Works

  1. Install or connect over USB. Web Serial lets the browser talk directly to the ESP32 for install and development.
  2. Save WiFi settings. The board stores network details and reconnects after reboot.
  3. Add online users. Username/password-derived keys are used for online sign-in and encrypted MQTT sessions.
  4. Use MQTT topics. The board listens for commands and publishes responses, events, and hello/status messages under its root/device topic.
  5. Keep USB as recovery. If online settings are wrong, USB remains the clean way back in.
