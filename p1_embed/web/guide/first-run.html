Absolute beginner path

First object walkthrough

This is the slow path from an empty board to a named, backed-up, scriptable XOBIT object. It assumes you have never used the project before.

Prepare Install Connect First Sketch Backup

1. Prepare

  • Use a Chrome-based browser. Web Serial works in Chrome and Edge. Safari and Firefox do not provide the same install path.
  • Use a data USB cable. Many USB cables only charge. If the board does not appear, try another cable first.
  • Keep one board connected. Multiple serial boards can make port selection confusing during first setup.
  • Know that install clears the board firmware. Use a board that is safe to flash with XOBIT.

2. Install Firmware

  1. Open the editor. Use the Open Editor button in the guide header.
  2. Open Install. Choose the Install tab in the editor.
  3. Connect the ESP32 over USB. Plug in the board, then use the browser’s serial chooser when prompted.
  4. Flash the current SafeBoot firmware. Follow the install panel. Wait until the install reports success before unplugging.
  5. Reconnect if needed. After flashing, the board may reboot and appear as a serial device again.
Recovery rule

If something goes wrong during online setup or OTA experiments, return to the Install tab over USB. USB is the trusted recovery path.

3. Connect And Name The Board

  1. Connect over USB. Use the editor connection controls to talk to the freshly installed board.
  2. Open Settings > General. Give the board a human name. This appears in the status bar and integrations.
  3. Open Settings > WiFi. Add your WiFi name and password. Save, then reboot if the board asks for it.
  4. Watch the status bar. It should show the board name, transport, running state, WiFi name, fps, and memory percent.
  5. Open Settings > Users. Add an online sign-in user if you want MQTT control without USB. WiFi by itself does not enable online control on a fresh board.

4. Upload A First Sketch

Start with a sketch that proves the compile/upload/log loop before adding LEDs or external parts.

// Prints a heartbeat once per second.
var lastPrintAt = 0;

function setup() {
  println("XOBIT ready");
}

function loop() {
  if ((millis() - lastPrintAt) >= 1000) {
    lastPrintAt = millis();
    println("alive");
  }
  delay(10);
}
  1. Create a new project. Name it after the physical thing you are making.
  2. Paste the sketch into Code. Upload it to the board.
  3. Read the console. You should see `XOBIT ready` and then `alive` once per second.
  4. Stop and upload again. Confirm you can stop the script, edit the message, and upload a revision.

5. Save The Work

  • Create a named revision. Use revision names that describe the behavior, not just “test”.
  • Export the project JSON. XOBIT is local-first; the browser does not automatically back up your sketches to a cloud account.
  • Keep wiring notes with the revision. Add circuit assumptions before you forget what the pins mean.
  • Move to a real object slowly. Add one physical part at a time, upload, test, and read the console.
