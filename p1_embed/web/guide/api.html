Script API

API guide

The API is the set of functions a script calls to reach XOBIT firmware features: pins, LEDs, UI controls, online services, Home Assistant, HTTP APIs, time, and diagnostics.

Choose An API Family

terminalCore runtime

Printing, timing, random values, heap checks, and script error helpers.

 wb_sunnyMath, time, sun

Math helpers, noise, local time, and daylight-aware values.

 memoryGPIO and PWM

Digital pins, analog input, touch, PWM, servos, and fans.

 wifiWiFi and device

Network status, device identity, uptime, memory, and reboot helpers.

 data_objectHTTP and JSON

Fetch APIs and read selected JSON values without filling script heap.

 flareLED strips

NeoPixel-style strip setup, pixels, brightness, HSV, and frame output.

 palettePalettes

Define color gradients and sample reusable RGB colors.

 settings_input_componentI2C and UART

Talk to external modules over I2C or UART ports.

Declare live controls, read UI events, and update displayed values.

 home_iot_deviceHome Assistant

Expose entities and consume Home Assistant events.
