# Third-party runtime dependencies

VJ1 vendors its browser runtime dependencies so a show does not depend on a CDN. Exact versions and file hashes are recorded in `dependency-lock.json`.

- p5.js 2.2.0 — GNU LGPL 2.1 or later; <https://p5js.org/copyright.html>
- TensorFlow.js 4.22.0 — Apache License 2.0; <https://github.com/tensorflow/tfjs>
- TensorFlow Models MobileNet 2.1.1 — Apache License 2.0; <https://github.com/tensorflow/tfjs-models>
- Material Symbols Rounded v365 — Apache License 2.0; <https://github.com/google/material-design-icons>
- Roboto Mono — Apache License 2.0; <https://github.com/googlefonts/RobotoMono>

The upstream copyright and license terms remain applicable to each vendored file.
