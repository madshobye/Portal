# Inferno panorama STL collection

Nine wide, low-poly performance scenes inspired by the circles of Dante's Inferno. Each binary STL combines many overlapping closed-shell elements into one shallow panoramic composition. They are visual assets, not fabrication-ready solids.

The X dimension is normalized to 100 units, Z rests on 0, and depth remains deliberately shallow. Triangle budgets are capped for layering multiple scenes in VJ1.

Regenerate with:

```sh
node experiments/vj1/tools/generate-inferno-panorama-stls.mjs
```
