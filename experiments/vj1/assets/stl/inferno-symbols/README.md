# Inferno symbolic STL collection

Five shallow 3D emblems derived from the symbolic forms in the supplied moodboard: eternity circles, descent spiral, faith cross, order square, and divine triangle. Each asset is an independent overlapping-shell binary STL optimized for realtime visual rendering.

Regenerate with:

```sh
node experiments/vj1/tools/generate-inferno-symbol-stls.mjs
```
