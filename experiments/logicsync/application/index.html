Live controls

Artist takeover has priority. Public controls cannot interrupt an artist.

DMX outputs

OutputFixturesFrames sent

Each fixture has 28 RGBW sections in 112H mode. Set start addresses 1, 113, 225 and 337 per output. Virtual RGB uses the R/G/B slots; W is zero.

Configuration

At least one fixture, at most four per output. Saved settings survive restart.

Network

Network changes take effect after restart. If DHCP is unavailable, the maintenance address becomes available after 45 seconds; DHCP is retried periodically.

Sunset schedule

Copenhagen · Sunset to 02:00 local time, with automatic summer/winter time. One uniform color, two-hour color cycle, 100% brightness subject to Maximum brightness. Manual changes return to this default after ten minutes. A clock sync is required after power-up.
